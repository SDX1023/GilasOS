# Welcome to StudyOS

This is a sample note to demonstrate the markdown rendering and [[wiki-links]] feature.

## Features

StudyOS includes:

- **Markdown Notes** with wiki-links
- **Flashcard Reviewers** with spaced repetition
- **Pomodoro Timer** for focused study
- **PDF to Flashcards** using AI

## Wiki-Links

You can link to other notes using `[[note-name]]` syntax. For example, check out the [[getting-started]] note for setup instructions.
